# Sistema ISP

Sistema web para la administración de Proveedores de Internet (ISP) con integración a MikroTik.

---

## Tecnologías

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- TanStack Query
- React Hook Form
- Zod
- Lucide React

### Backend

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT
- bcrypt
- dotenv
- CORS

## Instalación

### Clonar repositorio

```bash
git clone https://github.com/usuario/SistemaISP.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
